## 📖 Overview
A pure Java implementation of a classic 9x9 Sudoku grid solver. Using depth-first recursive backtracking with boundary checking, it solves complex Sudoku puzzles within milliseconds.

## ⚡ Algorithm Details
- **Strategy:** Recursive Backtracking (Depth-First Search)
- **Constraint Satisfaction:** Row, column, and 3x3 subgrid validation before cell assignment.
- **Space Efficiency:** In-place grid manipulation with clean stack unwinding.

## 💻 Running the Solver
```bash
git clone https://github.com/hasnain-kk/Sudoku_Solver.git
cd Sudoku_Solver
javac SudokuSolver.java
java SudokuSolver
```
